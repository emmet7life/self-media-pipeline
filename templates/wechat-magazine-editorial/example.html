Self Media LabIssue 001
Agent Native Workflow

别再把 Agent
当成聊天框

真正有价值的 Agent，是能读规则、调用工具、留下可追溯产物的工作流节点。

如果只让模型把 markdown 改成 HTML，最后得到的通常是一篇格式整齐但没有记忆点的文章。公众号读者需要的是节奏：标题、停顿、强调、案例、引用和可扫读的结构。

模板不是皮肤，而是内容被阅读的路径。

01 · 先决定读者的扫读路径

长文需要 masthead、deck、章节编号和 pull quote。它们让读者在三秒内知道这篇文章是否值得继续读。

适合：方法论、复盘、观点文、产品发布说明。不适合：纯口播稿或短促销。
